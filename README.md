# 🥛 Daily – The Smart Dairy

An intelligent, mobile-first decision-support & Agentic AI platform designed for rural dairy networks.

## 🚀 Key Features
- **Farmer Dashboard:** Herd management, ICAR feed formulation, AI health risk diagnostics, XGBoost milk yield forecasting, dynamic milk price predictor, and bilingual Kannada/English AI assistant.
- **Dairy Owner Dashboard:** Plant collection analytics, Twilio SMS payment receipts dispatch, and batch Excel ingestion.
- **Cattle Marketplace:** Peer-to-peer seller cattle listings with photo uploads and dynamic buyer filtering.

## 🛠️ Tech Stack
- **Frontend:** Streamlit (Python)
- **Database:** MySQL
- **Machine Learning & AI:** Scikit-Learn, XGBoost, ReAct Agent Core
- **Integrations:** Twilio SMS API Gateway
